# 노선도 검증

`npm run test:line-map`은 실제 순수 계산 TS를 읽어 확대 상한, 라벨, 터치 후보, 검색과 정적 경로 회귀 8개를 검사한다. DB에 접속하지 않는다. `npm run line-map:check`는 제작 원본과 JSON 산출물의 일치 및 v2 계약을 검사한다.

UI는 개발 서버의 `/tests/line-map/index.html`에서 확인한다. 제품의 `LineMapView`와 `AppShell`, 전체 도식을 그대로 사용하고 방문 데이터만 가짜로 공급한다. 운영 로그인·기록 저장 검증으로 해석하지 않는다. 프로덕션 빌드 엔트리에는 포함되지 않는다.

- 기본: 홍대입구 3회, 강남 1회, 잠실 123회.
- ‘연천역’은 도식 미보유 역 사례다. 검색에서 기록 링크만 제공하며 전체 역 방문 분모에는 포함하지 않는다.
- `?scenario=empty`: 방문 0건.
- `?scenario=loading`: 방문 집계 로딩.
- `?scenario=failed`: 방문 집계 실패.
- 검색 `ㅎㄷ`→홍대입구 ‘지도에서 보기’→역 클릭→복귀: 같은 위치/배율인지 확인.
- 공항철도 필터에서 홍대입구 강조, 전체 보기 복구, 방향키·Enter 이동을 확인.
- 360/390/480px와 데스크톱에서 가로 넘침·화면 밖 컨트롤·라벨 겹침을 확인.

실행 결과와 미검증 범위는 `docs/design/line-map-implementation-2026-10-06.md`에 기록한다.

# Android 실기기 검증

2026-11-17. 사용자가 준비 가능한 Android 휴대폰은 한 대다. 아직 USB 디버깅으로 연결된 기기가 감지되지 않아 아래 항목은 미실행 상태다. 브라우저 CI 통과와 APK 빌드 결과를 실기기 통과로 계산하지 않는다.

## 설치 준비

1. 개발자 옵션의 USB 디버깅을 켜고 PC에 USB로 연결한다. 휴대폰에서 PC의 디버깅을 허용한다. `adb devices -l`의 상태가 `device`여야 한다.
2. 기존 앱에 개인 기록이 있으면 암호화 백업을 기기 밖에 보관한다. 업데이트는 같은 서명의 APK로 `adb install -r`를 사용한다. 앱 삭제·저장 공간 초기화는 업데이트 검증을 대신하지 않는다.
3. `output/android/dongne-baljachwi-release.apk`를 설치한다. 디버그 키로 설치한 동일 패키지는 출시 키와 다르므로 덮어쓸 수 없다. 기존 데이터를 삭제해 해결하지 않는다.
4. 검증에는 별도로 만든 테스트 맵과 테스트 사진을 사용한다. 개인정보·사진·백업 암호를 로그나 이슈에 기록하지 않는다.

## 한 대에서 확인할 항목

| 항목 | 실행 방법과 기대 결과 | 결과 |
|---|---|---|
| 첫 시작 | 로그인 없이 빈 개인 맵으로 시작. 샘플 기록 자동 생성 없음 | 대기 |
| 기록·사진 CRUD | 서로 다른 역에 글·태그·사진을 작성하고 수정·삭제. 다른 기록은 유지 | 대기 |
| 사진 선택 | JPG/PNG/WebP 선택, 선택 취소, 손상/지원하지 않는 파일 거부. 기존 편집 내용 유지 | 대기 |
| 재시작 | 사진 포함 기록 저장 후 강제 종료·재시작. 글·사진·맵 선택 유지 | 대기 |
| 업데이트 | 같은 키의 다음 빌드를 덮어 설치하고 기존 글·사진·맵 유지 확인 | 대기 |
| 키보드·뒤로 가기 | 입력칸 가림·화면 넘침·의도치 않은 앱 종료·편집 내용 유실 확인 | 대기 |
| 오프라인 | 비행기 모드에서 기존 글·사진 열람과 개인 기록 저장. 공유 상태는 연결 실패로 안내 | 대기 |
| 백업 내보내기 | 암호화 파일을 공유 시트로 앱 밖에 보관. 작업 취소와 실제 파일 보관 여부도 확인 | 대기 |
| 복원 | 백업을 새 맵으로 복원하고 글·사진 비교. 원래 맵 유지. 잘못된 암호/손상 파일은 거부 | 대기 |
| 저장 공간 부족 | 테스트 환경에서 저장 실패를 재현. 기존 글·사진 보존. 개인 휴대폰의 저장 공간을 임의로 채우지 않음 | 대기 |

기기 모델·Android 버전·WebView 버전·설치 APK SHA-256·실행 날짜와 결과를 함께 기록한다. 개인 식별 기기 번호는 공개하지 않는다.

## 두 번째 휴대폰 또는 별도 기기가 필요한 항목

운영 HTTPS 공유 서버가 준비된 뒤 코드 발급·양쪽 확인·승인, 사진 전송, 다른 통신망, 전송 중단·재연결, 원본 오프라인, 오프라인 해제 재전달, 해제 후 양쪽 독립 수정, 실제 새 기기 백업 복원을 검증한다. PC 브라우저와 휴대폰 조합은 교차 환경 검증에 쓸 수 있지만 두 휴대폰 검증 완료로 표시하지 않는다.

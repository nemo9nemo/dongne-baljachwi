# 기기 저장·공유 코드·연결 해제 후 개인 맵

결정일: 2026-10-20. 사용자 승인: 공유코드 발급자 휴대폰을 원본 저장소로 사용하고, 연결을 끊으면 각자 개인 맵으로 전환한다.

이 문서는 새 기기 저장 방식의 구현 계약이다. 기본 실제 앱에 기기 저장·코드 승인·WebRTC 공유·개인 맵 전환을 구현했고 브라우저에서 검증했다. Android 저장 경로·프로젝트도 추가했으며 실기기 확인은 남아 있다. [구현 결과](../IMPLEMENTATION-2026-10-20.md)를 따른다. 기존 Supabase SQL의 공동 공간 해제는 별도 레거시 동작으로 보존한다.

## 저장과 공유

- 개인 기록은 각 기기의 영구 저장소에 보관한다. 사진은 캐시가 아니라 앱 전용 영구 파일로 저장한다.
- 공유코드를 만든 기기가 공유 원본을 제공한다. 초대받은 기기는 허용된 기록과 사진을 자기 기기에도 저장한다.
- 초기 공유는 1:1 읽기 전용으로 시작한다. 공동 편집은 별도 후속 계약이며 이번 승인으로 자동 추가하지 않는다.
- 코드는 최초 연결을 위한 만료 가능한 초대다. 연결 승인 후에는 기기별 권한을 사용한다. 코드만으로 모든 개인 기록을 읽을 수 있게 하지 않는다.
- 원본 기기와 연결될 때 변경을 가져온다. 원본이 연결되지 않을 때는 마지막으로 완전히 수신한 기록을 열람하고 마지막 동기화 시각을 표시한다.
- 인터넷을 통한 코드 연결의 신호 교환과 필요 시 전송 중계는 별도 서비스로 구성한다. 중계는 원본 사진의 영구 중앙 보관과 구분한다.

## 연결 해제: 각자 개인 맵

- 해제를 실행한 기기는 로컬에서 즉시 연결을 종료하고 해당 공유 맵을 독립 개인 맵으로 전환한다.
- 상대 기기는 해제 사실을 수신하면 자기 기기에 받은 공유 맵을 독립 개인 맵으로 전환한다. 상대가 오프라인이면 양쪽 전환이 동시에 완료됐다고 표시하지 않는다.
- 전환 후 각자는 보유한 기록·사진을 수정·삭제할 수 있다. 이후 변경은 이전 상대에게 전송하거나 반영하지 않는다.
- 해제 시점에 각 기기에 **완전히 수신된 기록과 사진**을 기준으로 한다. 상대 기기에만 있거나 아직 받지 못한 데이터까지 생기는 것으로 안내하지 않는다.
- 두 기기의 마지막 동기화 시점이 다르면 개인 맵 내용도 다를 수 있다. 동기화 대기·사진 미수신 여부를 해제 안내에 표시한다.
- 받은 기록을 남기는 것이 기본이다. 해제만으로 기록·사진을 삭제하거나 상대의 개인 기록 전체를 가져오지 않는다.
- 원래 작성자와 공유 출처는 이력으로 보존한다. 전환한 기기가 원래 작성자인 것처럼 변경하지 않는다.
- 기존 개인 맵이 있으면 조용히 덮어쓰거나 합치지 않는다. 공유 맵을 별도 개인 맵으로 보존하고 명시적 이동/합치기는 후속 기능으로 둔다.
- 재연결은 새 초대·승인으로 시작한다. 이전 개인 맵의 새 변경을 자동 업로드하거나 과거 공유 권한을 복원하지 않는다.

해제 안내의 기본 의미는 다음과 같다.

> 연결을 끊으면 이 기기에 받은 기록과 사진은 개인 맵으로 남아요. 이후 변경은 서로 공유되지 않아요. 아직 받지 못한 기록과 사진은 포함되지 않아요.

## 전환 중 데이터 보호

- 전환은 연결 상태·맵 소유 범위·동기화 세대를 함께 갱신하는 원자적 로컬 작업으로 처리한다. 중단 후 재시도해도 맵이나 기록이 중복 생성되지 않아야 한다.
- 내려받는 중인 응답은 연결 세대가 달라지면 반영하지 않는다. 해제 이후 도착한 응답이 개인 맵을 덮어쓰지 못하게 한다.
- 사진은 복사 완료/파일 존재를 검증한 항목만 보존한다. 여러 맵에서 같은 사진을 참조하면 참조가 남아 있는 파일을 정리 작업이 삭제하지 못하게 한다.
- 독립 개인 맵의 변경·백업·전체 삭제는 그 기기에서 관리한다. 상대 기기의 독립 사본을 원격 회수할 수 있다고 안내하지 않는다.
- 기존 서버 데이터나 계정을 자동 삭제하지 않는다. 이전과 삭제는 실제 데이터 대조·복원 검증 및 별도 전환 절차를 따른다.

## 구현 완료 기준

1. 허용된 기록만 공유되고, 개인 기록과 사진이 공유 범위 밖으로 전달되지 않는다.
2. 연결된 상태의 동기화, 원본 오프라인 상태의 기존 사본 열람을 실제 두 기기로 검증한다.
3. 해제 후 양쪽 개인 맵의 기록·사진이 유지되고, 한쪽의 수정/삭제가 다른 쪽에 반영되지 않는다.
4. 해제 중 앱 종료·늦은 응답·수신 중 사진·상대 오프라인·재연결을 검증한다.
5. 앱 재시작/업데이트 후에도 개인 맵이 유지되고 기기 밖 백업으로 새 기기에 복원된다.

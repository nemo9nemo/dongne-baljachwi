# 리비전 노트 — 인증 화면 / 웹 프레임 (2026-08-12)

> 1차 디자인 작업(`app-frame.md`) 결과물에 대한 사용자 피드백을 근거로 한 수정 지시.
> 스크린샷: `/login` 화면, 데스크톱 라이트·모바일 라이트·데스크톱 다크 3종.

## 사용자 반응

"수정이 필요해 너무 구려" — 뼈대(프레임 폭 480px·반응형·다크모드 대응)는 맞게 됐지만,
내용물이 스타일링되지 않은 와이어프레임 상태로 보인다는 지적.

## 방향 결정

**미니멀하고 깔끔하게.** 일러스트/장식 요소는 최소화하고, 타이포그래피와 여백만으로
위계를 만드는 모던 스타일. 아이콘·일러스트에 기대지 않는다.

## 구체적 문제 (심각도 순)

1. **카드 내부 상단 여백이 어색하게 큼.** `.screen`의 `justify-content: safe center`로
   콘텐츠가 프레임 안에서 수직 중앙 정렬되는데, 프레임 높이가 `min(100dvh - 64px, 900px)`로
   커서 로그인 폼 위에 목적 없는 빈 공간이 뜬다. **폼은 상단에 정박해야 자연스럽다.**
   미니멀 방향에서는 여백 자체가 디자인 요소이므로, 없애는 게 아니라 **의도가 있는 여백**으로
   바꿔야 한다 — 예: 상단 정렬 + 일관된 헤더 영역 확보.
2. **브랜드 정체성이 없다.** 로고·워드마크·아이콘 없이 텍스트 제목뿐이라 어떤 서비스인지
   화면만 보고 알 수 없다. 미니멀 방향이라도 최소한의 워드마크(텍스트 로고타입 수준으로도
   충분)는 필요하다.
3. **입력창이 기본 브라우저 폼처럼 밋밋하다.** 흰 배경 + 얇은 회색 테두리뿐, 포커스 시
   변화나 깊이감이 없다 (정적 스크린샷이라 hover/focus는 확인 못 했지만 기본 상태 자체가
   존재감이 없다).
4. **모바일에서 배경 그라데이션이 완전히 사라진다.** 모바일은 풀블리드 요구사항 때문에
   배경이 안 보이는데, 그 결과 데스크톱만 예쁘고 모바일(실제 주 사용 환경)은 더 밋밋해지는
   역전이 발생했다. 모바일에서도 최소한의 브랜드 톤(예: 상단 헤더 배경 밴드, 또는 은은한
   배경 틴트)이 있어야 한다.
5. **버튼이 존재감 없는 단색 블록.** 미니멀 방향에서도 primary 액션은 시각적으로 확실히
   구분돼야 한다 (그림자·톤 대비 등 절제된 방식으로).

## 하지 않을 것 (방향 확인됨)

- 일러스트, 캐릭터, 장식용 아이콘 남발 — 미니멀 방향과 배치됨.
- 프레임 폭/반응형 구조 자체는 유지 (480px, sticky 탭바 등 1차 작업은 유효).

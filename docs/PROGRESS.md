# 진행 현황

> 이 파일은 코드/스펙/디자인을 수정할 때마다 함께 갱신한다. 사용자가 이 파일 하나로
> 진행률을 확인하는 용도다. 표 항목을 완료했으면 상태를 바꾸고, 새로 생긴 미결정·작업은
> 바로 추가한다.
>
> 마지막 갱신: 2026-08-24 (노선도 좌표 5차 파일럿 실행 완료 — 5·6·8·9호선 155역. 원거리 역 제외 정책 적용 시작)

크기를 함께 고려한 판단값이다.

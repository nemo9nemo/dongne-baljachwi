## 적용한 변경
- 기록 카드: 감정·날씨 이모지와 태그 칩을 목록에서 숨기고 사진·기록을 우선 표시한다. 상세 데이터와 접근성 설명은 유지한다. 역 상세 링크의 테두리를 제거하고 사진 썸네일을 정사각형으로 통일한다.
- 작성: 역·날짜·사진·일기 순서로 배치하고 감정·날씨·태그는 선택 영역으로 접는다. 접어도 값은 유지된다.
- 사진 실패: 사진 동기화가 실패하면 저장된 사진 기준값을 갱신하지 않고 이탈 경고를 유지한다.
- 타임라인: 태그 필터를 접을 수 있도록 제공한다. 이전 필터 및 추가 페이지의 늦은 응답은 적용하지 않는다. 조회 중인 상태를 새 필터의 완료 캐시로 저장하지 않는다.
- 저장 안내: 서버의 일기 1,000자 제한과 오류 메시지를 일치시킨다.

## 브라우저 회귀 재실행
Vite 개발 서버를 별도 터미널에서 실행한다:

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174
```

Playwright가 설치된 Node 환경에서 실행한다. 이번 검증에는 Codex 번들 Playwright와 설치된 Edge를 사용했다. 번들 사용 시 `PLAYWRIGHT_MODULE`에 해당 Playwright 모듈의 절대 경로를 지정한다.

```powershell
$env:PLAYWRIGHT_MODULE = '<Playwright 모듈의 절대 경로>'
node tests/browser/run.mjs
```

서버 주소는 `TEST_BASE_URL`, 브라우저 채널은 `TEST_BROWSER_CHANNEL`로 지정할 수 있다. 기본값은 `http://127.0.0.1:5174`, `msedge`다. fixture는 실제 제품의 로그인·권한 검증을 대체하지 않는다.

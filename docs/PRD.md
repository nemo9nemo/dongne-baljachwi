## 1. 서비스 개요

**한 줄 정의**: 연인이 함께 다녀온 데이트 장소를 지하철 노선도 위에 기록하고, 사진과 일기로
추억을 남기는 커플 전용 데이트 아카이브 서비스.

**배경**: 커플이 다녀온 데이트 장소와 사진은 각자의 카메라 롤, 카카오톡 대화방, SNS에 흩어져
있어 시간이 지나면 언제 어디를 갔는지 기억이 흐려진다. 수도권 데이트는 지하철역을 기준으로
이동하는 경우가 많아, "노선도 위에 다녀온 역을 채워나가는" 방식이 실제 데이트 동선과 자연스럽게
맞아떨어지고, 빈칸을 채우는 수집의 재미도 준다. 커플만을 위한 비공개 기록 공간이라는 점에서
일반 SNS(인스타그램 등)와는 다른 정서적 가치를 준다.

**서비스 형태**: 반응형 웹. 모바일 우선 레이아웃으로 설계하되 데스크톱 브라우저에서도 동일하게
사용 가능.

**서비스명**: 동네 발자취 (가칭, 변경 가능)

## 2. 타겟 사용자

**페르소나 — 지하철로 데이트하는 20~30대 커플**

- 서울/수도권에 거주하며 주로 주말에 지하철을 타고 이동하며 데이트한다.
- 다녀온 장소와 사진이 여기저기 흩어져 있어 "우리가 어디 어디 가봤더라"를 한눈에 보고 싶어 한다.
- 100일, 1주년 같은 기념일에 그동안의 데이트를 돌아보는 걸 좋아한다.
- 다음 데이트 장소를 정할 때 아직 안 가본 곳을 참고하고 싶어 한다.

**사용자 시나리오**: 홍대입구역 근처에서 데이트를 마친 커플이 앱을 열고 노선도에서 홍대입구역을
누른다. "기록 추가"를 누르고 날짜를 확인한 뒤, 오늘의 기분(설렘)과 날씨(맑음)를 아이콘으로
고르고, 사진 두 장을 올리고, 짧게 일기를 쓴다. 태그로 "카페", "산책"을 추가하고 저장한다.
다음 날 프로필 화면에서 "다음에 가볼만한 역"에 뜬 성수역을 보고 다음 데이트 장소를 정한다.

## 4. 화면 구성 (7개)

| 화면 | 역할 |
|---|---|
| 노선도 (기본 화면) | 전체 노선 동시 표시, 셀렉트박스로 호선 필터, 역 클릭 시 역 상세로 이동 |
| 지도 보기 | 노선도 헤더의 토글로 전환. 기록이 있는 장소만 좌표 기반으로 핀 표시 |
| 역 상세 | 해당 역의 기록 목록 + 기록 추가 버튼 |
| 기록 작성/수정 | 역·날짜·감정·날씨·태그·사진·일기 입력 |
| 기록 상세 | 사진·일기 전문 열람, 수정/삭제/이미지로 저장 |
| 타임라인 | 전체 기록 최신순, 태그 칩으로 필터 |
| 프로필 | 커플 요약 통계, "다음에 가볼만한 역" 추천 |

화면 간 이동: 노선도/타임라인/프로필은 하단 탭으로 전환. 역 상세·기록 작성·기록 상세는 각
화면에서 드릴다운으로 진입하고 뒤로가기로 복귀한다.

## 5. 주요 기능 상세

### 5.1 노선도 화면

실제 노선도 형태처럼 역과 선을 그려 방문한 역은 호선 색으로 채워진 스탬프, 방문 안 한 역은 빈
원으로 표시한다. 기본값은 전체 노선을 한 화면에 겹쳐 그리고, 셀렉트박스에서 특정 호선을
고르면 그 노선만 강조되고 나머지는 흐려진다. 방문 횟수가 있는 역은 숫자 뱃지를 함께 보여준다.

### 5.2 감정·날씨 아이콘

기록 작성 시 그날의 감정(😊😍😆😌😢)과 날씨(☀️☁️🌧️❄️🌬️)를 아이콘 토글로 한 번에
선택한다. 텍스트 입력 없이도 기록 카드·상세 화면에서 그날 분위기가 한눈에 들어온다. 별도 텍스트
필드보다 입력 마찰이 적어서, 일기를 짧게 쓰거나 아예 안 쓴 기록도 기록다워 보이게 하는 효과가
있다.

### 5.3 자유 태그

Enter로 태그를 추가/삭제하는 단순한 입력 방식. 기록 카드에 최대 3개까지 미리보기로 노출하고,
타임라인 화면에서는 등장한 태그를 자동 수집해 칩 필터로 제공한다. 별도 추천 태그 사전 없이
사용자가 쓴 태그가 곧 필터 목록이 되는 구조라 구현 비용이 낮다.

### 5.4 기록 카드 이미지 저장

기록 상세의 메뉴에서 "이미지로 저장"을 누르면 역 이름·날짜·감정·날씨·태그·일기·사진을 카드
형태 PNG로 합성해 다운로드한다. 완전한 클라이언트 기능이라 서버 렌더링이 필요 없다.

### 5.5 안 가본 역 추천

프로필 화면에 "다음에 가볼만한 역" 섹션을 두어, 기록이 없는 역을 최대 4개 칩으로 보여주고
누르면 바로 그 역의 기록 작성으로 이어진다. 실제 서비스로 확장하려면 전국 역 마스터 데이터가
선행되어야 하며, 그전까지는 최근 방문이 뜸해진 역을 우선 보여주는 방식으로 축소해 시작할 수
있다.

## 6. 경쟁 서비스 분석

| 서비스명 | 강점 | 약점 | 우리와의 차별점 |
|---|---|---|---|
| 비트윈(Between) | 커플 전용 폐쇄형 채팅·일정·사진 앨범, 높은 인지도 | 장소를 시각적으로 모아보는 기능은 약함(앨범·캘린더 중심) | 지하철 노선도라는 공간 축으로 기록을 시각화 |
| 커플 다이어리류 앱 | 감성적인 일기 작성 UX | 장소 기반 지도·노선도 기능 부재 | 장소(역)와 일기를 1:1로 묶어 "어디서 무슨 일이 있었는지"가 바로 보임 |
| 카카오맵/네이버지도 즐겨찾기 | 정확한 지도 데이터, 저장 기능 | 커플 공유·일기·사진 등 기록 기능 없음 | 커플 공동 기록 + 노선도 게이미피케이션(빈 역 채우기) |

## 7. 현재 진행 상황

클릭 가능한 단일 HTML 프로토타입이 완성되어 있다(React, 목데이터, 로그인·백엔드 없음,
새로고침 시 초기화). 7개 화면 전체와 §3의 P0/P1 기능이 실제로 동작하는 상태로 구현돼 있고,
역 데이터 17개와 커플 정보 1쌍은 하드코딩된 값이다. 사진 업로드는 브라우저 로컬 미리보기만
되고 저장되지 않는다.
